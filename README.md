# Text Generation with Markov Chains

## Overview
This project implements a simple text generation model using Markov Chains.

A Markov Chain predicts the next word based on the current word's probability distribution learned from training text.

## Features
- Reads training text from a file
- Builds a word-level Markov model
- Generates random text sequences
- Easy to understand and implement

## Technologies Used
- Python
- Random Module

## How to Run

1. Clone repository
2. Add training text to sample_text.txt
3. Run:

python markov_generator.py
